# Evaluating ChatGPT, Gemini, and Claude in Generating Unit Tests for Python Programs

## Project Overview

This project presents an empirical study evaluating the ability of Large Language Models (LLMs) to generate Python unit tests for Python Programs.

Three LLMs are compared: ChatGPT, Gemini, and Claude, using a benchmark of 25 HumanEval programming tasks.

## Research Objectives

- Evaluate the quality of unit tests generated by different LLMs.
- Compare the generated tests using consistent evaluation criteria.
- Investigate test executability, correctness, and code coverage.
- Analyze the effectiveness of mutation testing in assessing test quality.

## Evaluated Models

- ChatGPT
- Gemini
- Claude

## Dataset

The study uses 25 programming tasks derived from the HumanEval benchmark. Each task includes a reference Python solution used to evaluate the generated test suites.

## Evaluation Metrics

The generated test suites are evaluated using:

- **Static Metrics:** Test functions, assertions, and test code characteristics.
- **Executability Rate:** Percentage of test suites that execute successfully.
- **Pass Rate:** Percentage of generated tests that pass against the reference solutions.
- **Code Coverage:** Line and branch coverage.
- **Mutation Score:** Ability of test suites to detect injected code changes.

## Project Structure

- `prompts/`: Prompts used to request test generation.
- `solutions/`: Reference Python solutions.
- `generated_tests/`: Unit tests generated by the evaluated LLMs.
- `results/`: Experimental evaluation results and figures.
- `llm_unit_test_evaluation.ipynb`: Main experimental notebook.
